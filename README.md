# Dipanshu Sahoo — Personal Portfolio

A high-performance personal portfolio built with [Astro](https://astro.build), featuring mathematical 4D Tesseract projection, real-time terminal emulator, Space Grotesk typography, and zero-bloat vanilla styling.

## 🚀 Tech Stack
- **Framework**: Astro 5 (Static Site Generation)
- **Typography**: Space Grotesk + DM Mono
- **Styling**: Vanilla CSS (Custom Design System & Tokens)
- **Interactive**: HTML5 Canvas (4D Tesseract projection) + Interactive Terminal
- **Deployment**: GitHub Pages via GitHub Actions

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production static bundle
npm run build
```
